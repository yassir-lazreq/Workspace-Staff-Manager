# Workspace-Staff-Manager

A simple staff management application built with HTML, CSS, and JavaScript. It allows you to add, view and delete employees and departments.

## Features

- Add new employees with details such as name, role, email, phone number, and photo.
- View detailed information about each employee, including their experiences.
- Delete employees from the system.
- Manage departments and assign employees to them.
- Real-time validation for input fields to ensure data integrity.
- Responsive and user-friendly interface.

## Installation

Clone the repository:

    ```bash
    git clone https://github.com/yassir-lazreq/Workspace-Staff-Manager.git
    ```

## Usage

1. To add a new employee, click on the "Add Employee" button and fill in the required details in the form.
2. To view an employee's details, click on their name in the employee list.
3. To delete an employee, click the "X" button next to their name in the employee list.
4. To manage departments, use the "Add Department" button and assign employees to them.
